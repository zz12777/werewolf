🎴 板子介紹
🤖 機械狼＋通靈師 ▶
機械狼：不與其他狼人相認、全程不可自爆，靠夜晚「學習」一名玩家的身份技能，次晚起就能使用該技能；等其餘狼隊友全滅後，機械狼會獨自帶刀殺人。
→ 查看機械狼完整規則

通靈師：每晚查驗一名玩家的具體角色（不只是好壞），若查到機械狼，還會顯示牠目前學到的身份，是抓機械狼的關鍵神職。
→ 查看通靈師完整規則
🌙 攝夢人＋夢魘 ▶
夢魘：在狼人行動前搶先發動技能，恐懼一名玩家使其當晚技能失效（若恐懼到隊友，狼人當晚就無法殺人）。
→ 查看夢魘完整規則

攝夢人：每晚指定一名「夢遊者」使其免疫當晚傷害；但攝夢人一旦死亡，夢遊者會一起陪葬，連續兩晚攝夢同一人對方也會死亡。
→ 查看攝夢人完整規則
💰 黑市商人＋狼兄狼弟 ▶
狼兄／狼弟：首夜互相確認身份；狼兄陣亡前，狼弟形同「隱狼」——不參與狼人殺人、查驗也顯示好人，直到狼兄陣亡的下一晚才會覺醒並被迫殺一人復仇，之後才正式加入狼窩。
→ 查看狼兄完整規則　→ 查看狼弟完整規則

黑市商人：整局限一次，可選一人進行交易，若對方是好人就成為「幸運兒」獲得查驗／毒藥／獵槍其中一項技能；但若誤與尚未覺醒的狼弟交易，交易會失敗且黑市商人隔天死亡，是這個板子最容易踩雷的地方。
→ 查看黑市商人完整規則
💋 狼美人＋騎士 ▶
狼美人：每晚必須魅惑一名玩家（不能連續兩晚選同一人），一旦狼美人出局或被毒，魅惑對象就會殉情陪葬。
→ 查看狼美人完整規則

騎士：白天發言時可隨時翻牌宣告決鬥：對方是狼直接淘汰進入黑夜，對方是好人則騎士自己以死謝罪；但若決鬥對象剛好是狼美人／黑狼王／白狼王，技能不會被觸發（不會殉情、不能開槍帶人）。
→ 查看騎士完整規則
🗿 石像鬼＋守墓人 ▶
石像鬼：每晚查驗一名玩家的具體角色；不與狼隊見面，隊友全滅前不能殺人，隊友全滅後可在查驗之外額外選擇今晚的帶刀對象殺人，不可自爆但可自刀。
→ 查看石像鬼完整規則

守墓人：從第二晚起，可以得知前一個白天被投票處死的玩家陣營（好人或狼人），能幫好人陣營在投票後持續累積情報。
→ 查看守墓人完整規則
🌑 血月使者＋獵魔人 ▶
血月使者：白天自己發言階段可自爆直接進入黑夜，並封印當晚所有神牌技能；若是最後一個被放逐的狼人，還能暫時存活到夜晚再殺一人，達成屠邊就直接獲勝。
→ 查看血月使者完整規則

獵魔人：從第二晚起可以狩獵一名玩家：對方是狼人則狼死，對方是好人則獵魔人自己死，且免疫女巫毒藥，是專門用來對抗血月的神職。
→ 查看獵魔人完整規則
🎩 魔術師＋黑/白狼王 ▶
魔術師：每晚最早行動，可以交換兩個號碼牌，當晚所有以號碼為目標的技能（狼刀、查驗、毒藥、守護等）都會被「換流」到對方身上，是很容易翻盤或誤傷隊友的關鍵神職。
→ 查看魔術師完整規則

黑狼王／白狼王：這個板子的狼王身分可以彈性選擇黑狼王或白狼王（法官在選角時二選一）。黑狼王被狼刀（夜槍）或被票出局（白天槍）淘汰時可以開槍帶走一名玩家，就算被守衛與女巫同時作用「奶穿」也照樣能帶人；但被女巫毒殺、或選擇自爆時，就不能發動這個技能。白狼王則是改成「自爆帶人」：白天除了投票環節以外的任何階段都可以主動自爆並帶走一名玩家，但被放逐、被獵人帶走、或夜間被隊友自刀時都不能帶人。
→ 查看黑狼王完整規則　→ 查看白狼王完整規則
🧬 混血兒＋黑/白狼王＋血月 ▶
混血兒：第一晚選擇一位玩家作為支持對象後就沒有其他夜間動作，勝負跟著支持對象的陣營走，但自己不知道對方是好是壞，全靠發言判斷；查驗永遠顯示好人，人數與屠邊判定上也算平民。
→ 查看混血兒完整規則

黑狼王／白狼王／血月使者：這個板子把混血兒和狼隊技能放在一起，其中狼王身分可以彈性選擇黑狼王（出局開槍帶人）或白狼王（自爆帶人），法官選角時二選一，讓好人陣營在推理和投票上都要更小心。
→ 查看黑狼王完整規則　→ 查看白狼王完整規則　→ 查看血月使者完整規則
🖤 惡靈騎士＋守衛 ▶
惡靈騎士：夜間免疫狼殺、女巫毒與夜槍，但被預言家查驗或被女巫毒殺後，隔天會反傷對方（預言家／女巫）死亡，是很容易讓神職誤觸的陷阱狼。
→ 查看惡靈騎士完整規則

守衛：每晚守護一名玩家使其免疫狼刀，不能連續兩晚守同一人；若與女巫同晚救同一人會「奶穿」，對方仍會死亡。
→ 查看守衛完整規則
💘 邱比特（情侶板） ▶
邱比特：全場第一個睜眼的角色，第一夜指定兩名玩家（可以鏈自己）成為情侶；兩人隨後互相確認彼此，但不知道誰是邱比特、也不知道對方陣營。若兩人陣營相同（人人鏈／狼狼鏈），邱比特的勝負跟著那個陣營走；若一人好人一人狼人（人狼鏈），邱比特與這對情侶會獨立成為第三方陣營，勝負規則完全不同（見下方「勝利條件」）。情侶其中一人死亡，另一人會立刻殉情，殉情者原本的技能不會發動。建議搭配 10 人（3神3民3狼+邱比特）或 13 人（4神4民4狼+邱比特）板子使用；本板狼隊刀人需刀型一致，不一致視為空刀。
→ 查看邱比特完整規則
🔮 狼巫＋純白之女 ▶
狼巫：與其餘狼人一同睜眼、參與商議選擇獵殺對象；刀口決定後，獨自睜眼查驗一名玩家的真實身份，第二夜起若查到純白之女，純白之女立即死亡（守衛與女巫都無法保護）。
→ 查看狼巫完整規則

純白之女：每晚查驗一名玩家的真實身份，第二夜起若查到狼人陣營，該名狼人立即死亡（守衛與女巫都無法保護）。若兩人剛好互查到對方、且分別是各自陣營最後一人，判定為「狼刀在先」，狼巫存活、純白之女死亡。
→ 查看純白之女完整規則
🎭 假面舞會（假面＋舞者） ▶
假面：不與狼隊見面、不可自爆；其餘正牌狼人全滅後可獨自帶刀殺人。第二夜起可先查驗一名玩家今晚是否在舞池中，之後可給予1名玩家面具，改變該玩家「當夜」在舞池陣營判定中的陣營；查驗與給予面具都不能連續兩晚指定同一人。
→ 查看假面完整規則

舞者：第二夜起每晚強制選3名玩家共舞（可以選自己），這3人若陣營相同無事發生，不同則人數較少的一方死亡；每位玩家整局只能共舞一次。若舞者選自己進入舞池，當晚舞池中所有人都免疫狼刀。
→ 查看舞者完整規則

🐺 大野狼＋小女孩 ▶
大野狼：與狼隊一同睜眼決定殺人對象，可以被隊友自刀，也可以自己自爆。只要場上四隻狼（狼人×3＋大野狼）全部存活，可以在女巫結束之後額外殺一人（跟正常狼刀分開，可能同時造成兩人死亡）；只要有任何一隻狼已經陣亡，這個技能就失效。
→ 查看大野狼完整規則

小女孩：每晚跟狼人牌一起睜眼、一起討論擊殺對象，但陣營仍是好人。第二夜起，狼隊選完刀口後有一次指認她的機會：指認成功，小女孩代替原本刀口死亡（守衛女巫都擋不住）；指認失敗，原本刀口照常結算。若狼隊不是靠指認、單純把刀口選在她身上，這只是一般狼刀，女巫仍可正常救她。
→ 查看小女孩完整規則
🤖 雙機械狼（大機械狼＋小機械狼） ▶
大機械狼／小機械狼：都不與其他狼見面，只在自己睜眼階段單獨睜眼；帶刀優先順序是「一般狼人 → 大機械狼 → 小機械狼」，前面的全滅才輪到後面的。兩隻都不能自爆。
第一晚可以學習一名玩家的技能，通靈師查驗會顯示學到的具體身分；第二晚起法官會告知學到的身分（但不會說是跟誰學的）。學到通靈師/女巫/獵人/守衛/平民/另一機械狼，各自有不同效果：
· 學到通靈師：下一晚起每晚可查驗一名玩家真實身分
· 學到女巫：下一晚起可在任一晚使用一次毒藥
· 學到獵人：淘汰時可以開槍帶走一人，被巫毒時無法開槍
· 學到守衛：下一晚起每晚可選擇守護一名玩家（不受狼刀/巫毒/夜槍傷害，不能連續兩晚守同一人），成功擋下一次傷害後這個技能就報銷了
· 學到平民：無特殊技能，僅被通靈師查驗時顯示為平民
· 學到另一個機械狼：第二晚可再重新選一人學習，但第一晚被通靈師查會顯示為機械狼身分
· 僅一個機械狼學到狼人：該機械狼在自己第一次輪到帶刀的那一晚會帶雙刀
· 兩個機械狼都學到狼人：小機械狼下一晚直接回歸狼隊，且當夜狼隊刀為無敵刀（可破守衛的盾）；大機械狼仍照原本順序，輪到時第一晚帶雙刀

🏆 勝利條件
🐺 狼人勝利：存活狼人數 ≥ 存活好人數，或所有神職死亡，或所有平民死亡
✓ 好人勝利：所有狼人被淘汰
💘 邱比特板（人狼鏈成立時）：邱比特＋情侶獨立成第三方陣營。第三方需屠光其餘所有玩家（屠城）才算獲勝；若第三方存活3人而場上其餘存活人數剩2人，直接判定第三方獲勝；若第三方人數少於3人，則與其餘玩家人數相當時，第三方獲勝。「狼人與好人陣營」除了原本各自的勝利條件，也都必須連同第三方（含邱比特）一起淘汰才算獲勝。

🗳️ 計票方式與平票 PK ▶
結果判定：多數票者出局。
平票怎麼辦？若最高票出現平票，自動進入 PK：平票玩家依「PK 發言順序」（見下方）再次發言，其餘玩家重新投票一次，票投給任一位 PK 候選人。

PK 發言順序：不論是警長競選（警上）還是白天投票放逐，PK 的發言順序都是「前一輪發言順序整個反過來」——前一輪越晚發言的人，PK 時越早發言；前一輪越早發言的人，PK 時越晚發言。

投票資格：
‧ 警長競選第一輪投票：只有從頭到尾都沒上警的玩家才能投票，曾經上警、後來退水的候選人這輪也不能投。
‧ 警長競選 PK 投票：除了正在 PK 的候選人以外，其他人都能投——包含已經退水的候選人、或第一輪有上警但沒有進入 PK 的候選人。
‧ 白天投票放逐（含 PK）：除了正在被投票的玩家（PK 候選人）以外，其他存活玩家都能投票。
💥 自爆吞警徽規則 ▶
是什麼：狼人在警長競選（警上）過程中主動自爆，讓警徽提前流失、拖慢好人陣營的查驗與投票節奏的操作。依照各房間／賽事規則不同，主流有兩種：

① 單爆吞警徽：首個白天的警上環節，只要有一名狼人自爆，警徽立刻流失，本局不再有警長。
流程：首日上警 → 狼人自爆 → 警徽流失、公佈死訊、發表遺言 → 進入黑夜。

② 雙爆吞警徽：需要 2 名狼人分兩天配合，難度較高。首個白天警上環節，第一名狼人先自爆，但警徽暫時保留，直接公佈死訊、發表遺言後進入黑夜；隔天白天重新競選警長，進行到退水環節時，第二名狼人再次自爆，警徽這才真正流失。
流程：首個白天 → 警上環節 → 狼人自爆 → 公佈死訊 → 進入黑夜 → 第二白天 → 再次競選警長 → 退水環節 → 狼人再次自爆 → 警徽流失 → 公佈死訊 → 進入黑夜。

補充說明：
‧ 自爆是主動技能，競選過程中的任何時候（起立、發言、退水前、投票前）都可以發動，發動後直接淘汰自己、不能開槍帶人，並跳過當輪投票直接公佈死訊、進入黑夜。
‧ 這裡討論的「自爆吞警徽」，專指警上競選期間的自爆；一般發言階段的「警下自爆」只是單純淘汰自己，若當時已經選出警長，警徽仍在警長身上、不受影響。
‧ 雙爆吞警徽規則下，若最終只有一名狼人完成自爆（另一狼沒有跟上），警徽不會流失：流程會停在「首日自爆 → 公佈死訊 → 天黑 → 隔天直接進入退水 → 投票」，警長依然照常選出。
‧ 法官の助手在「上警局」設定中可以直接選擇本局採用單爆或雙爆，開始主持後競選流程會自動依規則微調。
