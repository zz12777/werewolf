🎖️ 警長競選規則
🎖️ 流程與平票處理 ▶
基本流程：第一夜結束、天亮前先問是否上警，候選人起立 → 抽政見發表順序，依序發言 → 發言結束後可退水 → 未上警的玩家投票，最高票者當選警長 → 警長宣布警左／警右決定發言起始方向。

平票怎麼處理？
  • 如果最高票是 0 票（沒有人投票給任何候選人），本局無警長。
  • 如果最高票是非 0 的平票，平票的玩家進行新一輪發言 PK，然後重新投票，得票較多者當選警長；如果 PK 之後再度平票，本局不再有警長。
  • 狼人可以在競選環節的任何時間點自爆；狼人自爆會直接吞掉警徽，本局不再有警長。
PK 平票後還能退水嗎？ 原則上不行——進入投票環節、出現平票之後，參與 PK 的候選人不能再退水。
